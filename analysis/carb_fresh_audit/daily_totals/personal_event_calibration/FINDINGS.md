# Personal event calibration

The fixed personal corrections did not reach 10% daily error. Mean error increased. This tests average personal bias, not every possible personalization method.

| Model | Mean absolute percentage error | Days within 10% |
|---|---:|---:|
| Glucose + clock reference | 21.52% | 9/44 |
| Reference + additive correction | 23.10% | 13/44 |
| Reference + multiplicative correction | 23.90% | 13/44 |
| Glucose + clock + HR/activity | 21.10% | 16/44 |
| HR/activity + additive correction | 25.67% | 9/44 |
| HR/activity + multiplicative correction | 26.16% | 12/44 |

381 earlier meal predictions for each model were generated by refitting on other participants' allowed training meals and only the target participant's earlier, nonoverlapping response windows. Each person's day and future days were excluded when predicting that earlier day. Additive and multiplicative corrections used those out-of-sample predictions with fixed shrinkage of five pseudo-events. No later target was used to fit the correction. The two original reference predictions were reproduced within 1e-8 g per day.

For the HR/activity model, five of 16 participants changed residual sign between earlier and later meals. P15 previously needed +12.75 g per event on average, but later needed -3.53 g. P27 previously needed +17.11 g but later only +0.99 g. Applying the earlier correction therefore overshot. P13's mean residual was more consistent (+10.40 g earlier, +8.70 g later), illustrating why personalization helps some cases without solving the whole group. The glucose/clock reference had six sign reversals.

These comparisons describe model residuals, not causal changes in physiology. Earlier cross-fitted models have less same-person training history than the final model; this can itself change prediction bias. Different meals and activity patterns may also contribute, but this test cannot attribute causes. The next useful calibration design must account for response context and validate how its correction transfers as training history grows, rather than assuming a constant personal offset.

All 44 repeatedly inspected development days remain included. Meal times are supplied, so these are not passive results. No fresh validation or 10% success is claimed. The previous passive ensemble remains at approximately 18.40% mean error.

See `bias_transfer_audit.csv` for every participant, `earlier_predictions.csv` for the 762 out-of-sample predictions, and `daily_predictions.csv` for all evaluation outcomes. Source data and prior experiments were preserved.
