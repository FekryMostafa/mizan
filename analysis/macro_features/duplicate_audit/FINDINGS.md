# Duplicate check of the earlier eligible CGM cohorts

Rechecked all 652 CGMacros and 86 BIG IDEAs development curves used in recent feature and calibration work. The curve manifest's feature-file hash matches the current features, and every curve's peak reproduces the extracted feature within 1e-6.

No duplicate pairs were found within or between these datasets using any of three fingerprints: exact baseline-relative 37-point curves, absolute curves rounded to six decimals, or curves shifted to their first point and rounded to six decimals. The latter checks identical shapes even when their starting glucose differs. Reserved participants were not accessed.

The Stanford exact-duplication finding therefore does not invalidate these particular earlier inputs. This check is limited to the existing eligible 0–180 minute windows. It does not certify original-record independence, exclude near-duplicates under looser tolerances, or eliminate recipe, schedule, preprocessing or model-selection leakage. It establishes no new macro-prediction accuracy.

All fingerprints, input hashes and counts are saved alongside this report. The earlier ±10% failures remain the measured outcome.
