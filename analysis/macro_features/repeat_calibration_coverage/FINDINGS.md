# Repeated-calibration coverage

8 September 2026. Averaging two calibration repetitions per dose leaves **zero later evaluation meals** for the exact dose contrasts in the eligible records. Fitting those same repetitions and reporting reconstruction accuracy would reuse calibration data.

Enumerated all distinct dose pairs within each person while holding the other two recorded macros exactly equal, across all 652 eligible CGMacros and 86 BIG IDEAs development meals. This search was broader than the controlled breakfasts: it did not require matching fiber or meal type.

| Dataset / macro | Dose pairs | Pairs with two records at each dose | Pairs with a later query after two-per-dose calibration |
|---|---:|---:|---:|
| CGMacros carbohydrate | 36 | 27 | 0 |
| CGMacros protein | 35 | 28 | 0 |
| CGMacros fat | 33 | 25 | 0 |
| BIG IDEAs carbohydrate | 1 | 0 | 0 |
| BIG IDEAs protein | 1 | 0 | 0 |
| BIG IDEAs fat | 0 | 0 | 0 |

Also checked the full 1,706-event CGMacros table before CGM eligibility filters. For the reference contrasts (24/66 g carbohydrate, 22/66 g protein, 10.5/42 g fat), no person has more than two records of either reference dose. Relaxing sensor quality filters cannot reveal a third recorded repetition of these conditions.

The arithmetic minimum for this particular check is three sessions per dose: two earlier calibration sessions and one later evaluation session. This is not a statistically adequate sample-size recommendation. A credible ±10% claim also needs sufficient independent evaluations, reliably measured intake, and new portions and compositions absent from calibration.

The saved inventory lists every candidate's person, dose levels, counts and chronological availability. Reserved participants were not opened. This is a coverage limit for the proposed repeated-dose test, not proof that every CGM inference method is impossible. Population-assisted calibration remains a different possible analysis; it would not validate the missing multiple-repeat personal experiment. No new hardware, outreach or human experiment was performed.
